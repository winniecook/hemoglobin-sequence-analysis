# hemoglobin-sequence-analysis

# Hemoglobin Sequence Analysis with Biopython

This project demonstrates the use of Biopython to analyse hemoglobin sequences. It serves as a practical example of various sequence analysis techniques and Biopython functionalities.

## Project Overview

The script performs the following operations:

1. Fetches hemoglobin sequences from NCBI
2. Parses and iterates through sequence files
3. Extracts information using list comprehensions
4. Demonstrates accessing and manipulating sequence records
5. Extracts and modifies annotations
6. Converts between file formats
7. Uses dictionary-like operations on sequences
8. Implements sequence indexing
9. Writes and modifies sequences
10. Works with compressed files
11. Uses low-level sequence parsers
12. Performs sequence manipulation and StringIO operations
13. Creates custom sequence records and features

## Requirements

- Python 3.7+
- Biopython 1.79+

See `requirements.txt` for detailed package information.

## Usage

1. Clone this repository: git clone https://github.com/winniecook/hemoglobin-sequence-analysis.git
2. Install the required packages: pip install -r requirements.txt
3. Run the script: python3 hemoglobin_analysis_3.py
